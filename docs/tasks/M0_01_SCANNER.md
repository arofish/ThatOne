# M0-01：只读候选图片扫描器

## 需求

让 PhotoIndex 找到用户指定目录里的候选图片文件，保持原始文件不变。最终接口为 `scan_images(root: Path) -> list[Path]`，实现位置 `photoindex/scanner.py`。暂不需要安装包配置或命令行入口。

## 必要概念

- `Path` 表示文件系统路径；`suffix` 是末尾扩展名，不能证明文件是有效图片。
- 单层遍历只查看直接子项；递归遍历会继续进入子目录。
- 符号链接指向其他位置，跟随它可能越过资料库边界或形成循环。
- 排序让相同目录内容获得稳定输出，便于测试和之后比较扫描结果。
- 抛出异常表示扫描没能成功完成；空列表表示成功扫描但没有候选文件。两者不能混淆。

先学习当前小步需要的部分，不要求一次掌握全部。

## 最终接口约定

| 场景 | 行为 |
| --- | --- |
| 有效目录 | 返回递归发现的候选普通文件绝对路径列表 |
| 扩展名 | 仅 `.jpg`、`.jpeg`、`.png`，大小写不敏感 |
| 排序 | 按完整路径的字符串升序，结果不重复 |
| 隐藏项 | 包含；不做隐藏目录过滤 |
| 子目录或文件符号链接 | 跳过，不跟随；应先判链接再判文件/目录 |
| 根路径本身为符号链接 | 允许解析到真实目录；仍跳过其子树中的链接 |
| 空目录或只有非候选文件 | 返回 `[]` |
| 根路径不存在 | 抛出 `FileNotFoundError` |
| 根路径是普通文件 | 抛出 `NotADirectoryError` |
| 访问受限或扫描期间读取失败 | 传播对应 `OSError`，不能吞掉后返回“成功” |

扫描前规范化根路径。扫描期间目录仍可能变化；M0 不承诺文件系统快照，也不自动重试。选择遍历方法时注意其错误策略，有些递归便利方法会忽略读取错误。

## M0 验收清单

- 单层、嵌套目录中的大小写扩展名均能识别。
- `.txt` 文件及名为 `fake.jpg` 的目录不会被返回。
- 空目录、无候选文件返回空列表。
- 缺失目录与文件作为根路径分别抛出约定异常。
- 隐藏目录被扫描；文件链接、目录链接以及指向祖先的链接被跳过。
- 相对根路径产生绝对路径；重复调用输出相同且有序。
- 读取错误明确传播。用可控模拟触发读取失败；真实权限测试若受运行身份影响，需要说明，不能仅靠改权限后未报错判定成功。
- 调用前后样本文件内容、大小和修改时间保持一致，未新增或删除样本文件；不把系统可能更新的访问时间作为失败标准。
- 在明确的 Python 环境下运行 `python3 -m unittest discover -s tests -v`，记录实际结果；未执行不能标记通过。
- 本阶段不设毫秒级性能门槛、不做压力优化。能解释按目录项数遍历、按候选数排序的成本即可。
