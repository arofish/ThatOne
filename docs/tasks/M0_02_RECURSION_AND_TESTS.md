## 任务 A：规范化根路径并保留读取错误

必要概念：路径规范化、文件元数据、文件类型、异常传播。

- 扫描前解析根路径，允许根本身是指向目录的符号链接。
- 根不存在时抛 `FileNotFoundError`，根是普通文件时抛 `NotADirectoryError`。
- 根元数据读取、目录枚举、子项元数据读取失败时，传播对应 `OSError`；不能将权限错误改成不存在，也不能跳过失败项后正常返回。
- 子树内的符号链接（包括失效链接）全部跳过。

提示：阅读 `Path.stat()`、`Path.lstat()` 或 `stat(follow_symlinks=False)` 的区别，以及 `stat` 模块的 `S_ISLNK`、`S_ISDIR`、`S_ISREG`。元数据读取返回文件类型信息；依据这份信息判断类型，可以避免用可能隐藏读取错误的布尔查询。子项要先识别链接，不能先跟随链接读取目标。不要用大范围 `except OSError: continue`。

验收：缺失根、文件根、有效根链接符合契约；受控模拟根元数据、子项元数据和目录枚举各抛一次 `PermissionError`，调用都必须抛出该异常。异常发生前已经收集到一些候选也不能正常返回部分结果。

## 任务 B：递归访问全部真实子目录

必要概念：递归或显式栈、目录访问与文件收集的区别。

- 扫描所有层级，包含隐藏目录；目录名称带 `.jpg` 也只能按目录处理。
- 普通文件仅保留 `.jpg`、`.jpeg`、`.png`，大小写不敏感；不检查图片内容。
- 不跟随文件链接、目录链接或指向祖先的链接。
- 最后对全部候选按完整路径字符串升序排序，返回绝对路径且不重复。

本批使用 `iterdir()` 配合显式栈：列表尾部加入、尾部取出，实现深度优先访问。这样可以直接观察待访问目录，也不受 Python 函数递归深度的限制。项目声明 Python >=3.11，不能在未调整支持范围的情况下无意引入仅新版本可用的接口。

先在纸上或注释中列出下面目录的一个访问顺序，说明为什么不会漏掉兄弟目录、为什么另加的指向根目录的 `loop` 链接不会造成循环。扫描顺序可以不同，但返回结果必须一致。

## 任务 C：用临时目录编写自动化测试

使用 `unittest.TestCase`、`tempfile.TemporaryDirectory`，错误测试使用 `unittest.mock`。测试需要断言，不能只 `print`。

基础夹具（文件内容可为空或任意占位字节）：

```text
root/
├── A.JPG
├── b.jpeg
├── notes.txt
├── fake.jpg/              # 空目录
├── album/
│   ├── c.png
│   └── deep/
│       └── d.JpEg
└── .hidden/
    └── e.PNG
```

基础夹具恰好返回 5 个候选：`A.JPG`、`b.jpeg`、`album/c.png`、`album/deep/d.JpEg`、`.hidden/e.PNG`。比较时将预期项转换为解析后的绝对路径，再按字符串排序，不按树中展示顺序断言。

| 测试组 | 必须断言的结果 |
| --- | --- |
| 单层与嵌套筛选 | 上述 5 项完整相等；`.txt`、额外 `.webp` 及 `fake.jpg` 目录不入结果；空的 `.jpg` 可以入结果。另测向 `fake.jpg/` 添加 `inside.png` 后，该文件必须被找到 |
| 隐藏项 | 隐藏目录和另行添加的隐藏图片文件均包含 |
| 无候选 | 空目录、仅含非候选文件的目录都返回 `[]` |
| 无效根 | 缺失根与普通文件根分别抛约定异常 |
| 路径与顺序 | 相对根产生预期绝对路径；重复调用完全一致；结果有序且无重复 |
| 链接 | 添加文件链接、目录链接、祖先链接与失效链接，结果仍等于原候选，能够结束；根链接扫描与真实根一致。至少有文件/目录链接指向扫描根外的临时候选，确认它们不泄漏进结果 |
| 错误 | 根元数据、子项元数据、嵌套目录枚举的受控错误都原样暴露；已有候选也不返回部分成功 |
| 只读 | 扫描前后文件内容、大小、`st_mtime_ns` 和目录成员一致；不检查访问时间 |

错误测试应模拟实际读取操作抛异常，不要模拟 `scan_images` 本身，也不要只给布尔类型判断设置返回值。确认被替换的读取操作确实被调用、目标异常确实被触发；否则不能证明错误路径通过。当前 Python 3.14 实现用 `os.stat` 注入可以触发现有问题，仅替换 `Path.stat` 未必命中当前布尔查询内部路径；修改实现后按实际调用位置选择模拟点。将模拟范围限制在目标路径或目标调用，避免夹具创建与清理受影响。可先写使当前错误处理失败的测试，再修改业务实现。macOS 临时目录可能经过 `/var` 到 `/private/var` 的路径解析，夹具根先规范化可避免路径拼写差异导致误报。

根外链接目标也放在同一个 `TemporaryDirectory` 中：其中一个子目录作为扫描根，另一个作为外部目标。不要为这些测试使用真实照片目录。

“已有候选后遇错”的用例要受控安排枚举顺序，确保先收集一个候选，再触发失败；不能依赖文件创建顺序或文件系统自然返回的顺序。异常类型必须正确，不额外要求异常对象身份相同。

现有 `tests/scaner_test.py` 可保留为手动演示；不要只重命名它，因为单纯打印仍然不是自动化测试。正式测试不能依赖私人 `photos/` 或本机绝对路径。
